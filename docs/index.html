Access Control

User
Roles

Five distinct access tiers, each with a different authentication method and capability set. Face recognition for PE members. Password-based for management roles.

PIC

Person In Charge

  • Manage full drill database (add, edit, remove)
  • Record stock-in and stock-out transactions
  • Submit orders for approval
  • View full order history and analytics
  • Receive low-stock and delivery email alerts
APPROVER 1

First Level Approval

  • Review pending orders, toggle approve / reject per line item
  • Forward approved items to Approver 2 with auto email
  • Manage employee accounts and face enrollment
  • View stock monitoring and analytics
APPROVER 2

Final Authority

  • Final approval decision on all orders
  • Auto-generate PDF summary on submission
  • Broadcast approval email to all stakeholders
  • View full monitoring dashboard
PE MEMBER / USER

Production Engineer

  • Face scan login via MTCNN + LBPH recognition
  • Stock-out requests only
  • View current stock status
  • Guest signup with Approver 1 review
Workflow

Order Approval
Flow

A structured, four-step cycle from low-stock identification to delivery logging. Every step triggers an automated Outlook email. No manual follow-ups needed.

01
PIC Identifies Low Stock & Submits Order
OrderManagement page flags items below safety stock threshold. PIC sets order quantities, checks items, and submits — generating an Order ID and emailing Approver 1 automatically.
02
Approver 1 Reviews Per Line Item
Toggle approve/reject on each order item individually. Approved items advance to Approver 2 with an automated email notification. Rejected items logged with reason.
03
Approver 2 — Final Decision
Final authority. On submission, auto-generates a PDF approval summary and emails all stakeholders — PIC, Approver 1, and Approver 2 — simultaneously via Outlook.
04
PIC Records Delivery, Stock Auto-Updates
Order History shows approved orders awaiting delivery. Recording a delivery auto-increments current stock level and logs the transaction with timestamp and quantity.
Core Features

What It
Does

🧠

Face Recognition Login

PE members authenticate via face scan using MTCNN detection (facenet-pytorch) and LBPH recognition (OpenCV). Faces enrolled and retrained per employee — no passwords required for operators.

📦

Real-Time Stock Tracking

Live stock-in / stock-out recording with safety stock comparison. Items below threshold trigger automated low-stock email alerts to PIC and Approver 1 via win32com Outlook integration.

✅

2-Tier Approval System

Structured order approval through Approver 1 → Approver 2. Toggle approve/reject per line item. Auto PDF report + email summary on final approval. Full audit trail maintained.

📊

Analytics Dashboard

Interactive Matplotlib charts: drill orders by period, cost trends, top-10 usage, type breakdown. Hover tooltips and popup zoom for deeper inspection. Filter by custom date ranges.

🔄

Multi-User File Sync

QFileSystemWatcher + 2-second polling keeps all open sessions in sync across the network share. Multiple users can operate simultaneously — no server, no database required.

📧

Outlook Email Automation

Automated notifications via win32com for every workflow event: order submissions, approval decisions, delivery reminders, low-stock alerts, and guest account approvals.

Architecture

How It's
Built

Layered architecture — UI, business logic, and data access are cleanly separated. Face data, Excel workbooks, and PDF output all live on a shared network path for multi-user access.
